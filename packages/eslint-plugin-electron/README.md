# @noctcore/eslint-plugin-electron

Electron security rules for the main process: renderer isolation flags that must not be turned off,
IPC handlers that check who sent the message before acting on it, and `shell` calls kept to the one
module that checks what it hands to the operating system.

**Docs:** [noctcore.github.io/eslint-plugins/packages/electron](https://noctcore.github.io/eslint-plugins/packages/electron/)

Not a good fit for anything but an Electron app, where it does nothing.

## Requirements

- ESLint 9 or 10, flat config (`eslint.config.js`) only.
- `configs.recommended` registers the plugin and sets rule severities, nothing else. It sets no
  `files` and no parser, so it applies to whatever files the rest of your config lints. To lint
  TypeScript, add a `files` pattern and `@typescript-eslint/parser`, as in the quick start.

## Install

```sh
bun add -D @noctcore/eslint-plugin-electron @typescript-eslint/parser   # or npm i -D / pnpm add -D
```

## Quick start

```js
// eslint.config.js
import tsParser from '@typescript-eslint/parser';
import electron from '@noctcore/eslint-plugin-electron';

export default [
  {
    ...electron.configs.recommended,
    files: ['src/main/**/*.ts'],
    languageOptions: { parser: tsParser },
  },
];
```

## Opt-in rules

`recommended` turns on `webpreferences-locked` only. The other two need a fact about your app: the
module that may use `shell`, and the function that checks an IPC sender. Turn them on with both:

```js
// eslint.config.js
export default [
  // ...the quick start's entry, then:
  {
    files: ['src/main/**/*.ts'],
    languageOptions: { parser: tsParser },
    rules: {
      'noctcore-electron/no-shell-outside-allowlist': ['error', { allowIn: ['**/src/main/external-links.ts'] }],
      'noctcore-electron/ipc-handler-validates-sender': ['error', { guards: ['isTrustedSender'] }],
    },
  },
];
```

## Severity policy

Every rule is `error` or `off`, never `warn`: a warning is a rule nobody obeys. See the
[severity policy](https://noctcore.github.io/eslint-plugins/getting-started/#severity-policy).
